# TimePRO for Home Assistant

The personal TimePRO planner, running on your Home Assistant host. Open its Web UI
to configure a provider, connect Nextcloud and display a rotating phone-pairing QR.
Your Android app remains the daily interface.

This is a development preview. It does not provide hosted E2EE, wake-word detection,
phone app blocking or the full intended travel/weather assistant.

See **Documentation** for installation, HTTPS and local-model requirements.
